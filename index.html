            Answers to the questions that keep coming up around CoD2 configs.
            

			
            
				
            The tools
            

				
            
					
            Which tab do I need?
            
					
              
						
            • name generator: a colored player name, previewed in the game's font.
              • 
						
            • chat generator: colored chat messages as binds.
              • 
						
            • config checker: what the game does with every line of a .cfg.
              • 
						
            • server config: a server.cfg for a zPAM server.
              • 
						
            • maps: the stock maps, their internal names and what zPAM changes.
              • 
						
            • dvars and rcon: every dvar and every rcon command, with defaults and syntax.
              • 
					
            
				
            

				
            
					
            How do I use a line from these tools?
            
					
            Open the console with ~ and paste the line with a slash in front, for example
						/seta name "^1Player". To keep it, put the line into your config instead. Nothing you
						type here leaves your browser.
            
				
            

				
            
					
            Where is my config?
            
					
            In CoD2 1.3 it is main/players/<your profile>/config_mp.cfg. CoD2x
						always uses main/config_mp.cfg. The game writes your changed settings back into it.
            
				
            
			
            

			
            
				
            Names, chat and settings
            

				
            
					
            Why are the colors of my name gone in chat?
            
					
            The game removes color codes from the name in chat and in the name above a player; there the
						name shows in the team color. The scoreboard keeps your colors. The text of a chat message keeps its
						codes.
            
				
            

				
            
					
            What do ^8 and ^9 show?
            
					
            The team colors: ^8 the allies, ^9 the axis. The map's script sets them, so ^8 is green,
						blue or red depending on whether the allies are American, British or Russian.
            
				
            

				
            
					
            Why does a setting not stick?
            
					
            It may be cheat protected (only with sv_cheats 1), read-only, out of range, or
						set by the server: zPAM sets some settings when you join a team, and CoD2x locks others on match
						servers. The config checker says which one it is
						for every line.
            
				
            
			
            

			
            
				
            Servers
            

				
            
					
            How do I set up a zPAM server?
            
					
              
						
            1. Put zPAM's .iwd and zpam_maps_v7.iwd into main; leave
							fs_game empty.
              2. 
						
            2. Make a server.cfg with the server config tab and
							put it into main.
              3. 
						
            3. Start the server with +set dedicated 2 +exec server.cfg.
              4. 
					
            
					
            zPAM needs web download (sv_wwwDownload 1 and a working
						sv_wwwBaseURL) so players get its files fast.
